ejercicio 52

Este ejercicio tiene que tener una pagina estos requisitos:
Enunciado Una tienda online quiere ofrecer a sus clientes la posibilidad de personalizar una camiseta antes de comprarla.
Tu tarea consiste en crear una página web que contenga un formulario HTML donde el usuario pueda introducir sus datos y elegir las características de su camiseta.Requisitos del formulario
El formulario deberá incluir los siguientes elementos:Nombre del cliente: Un campo de texto para introducir su nombre.Correo electrónico: Un campo de tipo email.Color de la camiseta: Un selector de color utilizando input type="color".Tamaño del diseño: Un control deslizante utilizando input type="range" que permita seleccionar un tamaño entre 10 y 100.Cantidad de camisetas: Un campo numérico que permita seleccionar entre 1 y 20 unidades.Comentarios adicionales: Un área de texto donde el cliente pueda escribir indicaciones.Botón de enviar: Un botón para enviar el formulario.Botón de limpiar: Un botón para restablecer los valores del formulario.
